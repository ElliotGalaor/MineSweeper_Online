# Minesweeper - Java Project

## Description
Implementation of a Minesweeper game in Java as part of a school project. The game features a complete graphical interface with classic Minesweeper mechanics. An online functionnality is under development.

## Features

### ✅ Implemented
- **Graphical Interface** : Interactive grid in Swing/JavaFX
- **Gameplay** : Cell revelation, mine marking, victory/defeat detection
- **Difficulty Levels** : Easy, Medium, Hard, Impossible
- **Standard Rules** : Adjacent mine display, cascade overflow

### 🔄 In Development
- **Online Mode** : Multiplayer functionality in development
  - Player connection
  - Game board synchronization
  - Point system / Battle Royale
